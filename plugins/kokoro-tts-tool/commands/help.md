Display help information for kokoro-tts-tool CLI commands.

## Usage

```bash
# Show general help
kokoro-tts-tool --help

# Show command-specific help
kokoro-tts-tool COMMAND --help

# Show version
kokoro-tts-tool --version
```

## Arguments

- `COMMAND` (optional): Specific command to get help for
- `--help` / `-h`: Show help information
- `--version` / `-v`: Show version information

## Examples

```bash
# General help
kokoro-tts-tool --help

# Command help
kokoro-tts-tool search --help

# Version information
kokoro-tts-tool --version
```

## Output

Displays usage information, available commands, and options.
